# Model Memory - Quick User Guide

## What is it?

The app now remembers images generated by each model, so you can quickly compare results without waiting for regeneration.

## Visual Indicator

Models that have generated images show a checkmark: **✓ Model Name**

## How to Use

### Compare Multiple Models

1. Enter your prompt: `"A cat wearing a hat"`
2. Click **Flux Schnell** → Image generates, button shows **✓ Flux Schnell**
3. Click **Flux Pro** → Image generates, button shows **✓ Flux Pro**
4. Click **✓ Flux Schnell** → Instantly shows first image (no wait!)
5. Click **✓ Flux Pro** → Instantly shows second image (no wait!)

### Try a New Prompt

1. Change your prompt to `"A dog on the beach"`
2. Press **Enter** or click **Generate**
3. All ✓ marks disappear (cache cleared)
4. Fresh generation starts with new prompt

## Quick Tips

- **Instant switching**: Click a different ✓ marked model to see its cached image
- **Force regenerate**: Click the currently selected model to regenerate with it
- **Auto-clear**: Cache automatically clears when you change the prompt
- **Memory only**: Images are not saved to disk, only in memory
- **Compare easily**: Generate with multiple models, then quickly switch between them

## When Cache Clears

The cache is automatically cleared when:
- You change the prompt text and trigger generation
- You enhance the prompt (Enhance or Enhance... buttons)
- Any generation starts with a different prompt

## Benefits

✅ **Faster workflow** - No waiting when switching models  
✅ **Easy comparison** - Quickly view outputs side-by-side  
✅ **Visual feedback** - Clear indication of tried models  
✅ **Automatic management** - Cache handles itself

## Example Workflow

```
1. Prompt: "sunset over ocean"
   Generate with Flux Schnell ✓
   Generate with Flux Pro ✓
   
2. Compare:
   Click ✓ Flux Schnell → instant view
   Click ✓ Flux Pro → instant view
   
3. New idea: "mountain landscape"
   Change prompt → all ✓ disappear

```
